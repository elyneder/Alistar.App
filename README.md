# Alistar.App

Um aplicativo desenvolvido em C# para gerenciamento e organização de informações relacionadas ao processo de alistamento.

## 🚀 Começando

Essas instruções permitirão que você obtenha uma cópia do projeto em operação na sua máquina local para fins de desenvolvimento e teste.

Consulte **Implantação** para saber como implantar o projeto.

### Clonando o projeto

Faça o clone do repositório:

```bash
git clone https://github.com/elyneder/Alistar.App.git
```

Acesse a pasta do projeto:

```bash
cd Alistar.App
```

Abra o projeto utilizando uma IDE compatível com C#, como o Visual Studio.
